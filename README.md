# Online Shopping Cart System

## About the Project
A shopping cart application that demonstrates basic product management and order total calculation. This project can be implemented in C or C++.

## Features
- Display available products
- Add products to the cart
- View cart items
- Calculate the total price
- Manage cart items, if implemented

## Technologies Used
- C / C++
- Data Structures

## Concepts Used
Arrays, structures, functions, loops, and calculations.

## How to Run
Compile the source code with a compatible C or C++ compiler and run the program.

## Learning Objective
To understand product handling, cart operations, and basic transaction calculations.
